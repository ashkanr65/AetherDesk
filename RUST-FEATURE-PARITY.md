# Native Rust feature parity

Updated 2026-10-14. This is a migration in progress, **not a completed feature-equivalent replacement**. Native SSH+X11, remote video/input, popup editing, protected native credentials, AI chat/actions, Tools and logs now have source implementations. The user subsequently authorized R12 compilation/runtime acceptance: 211 Windows and 91 Linux native checks, selected live-host/provider checks and clean Windows Sandbox package checks passed. See `R12-ACCEPTANCE.md`; catalog rows retain `implemented_unverified` until their full live/workflow requirements pass.

The inventory maps 56 behavior groups and 475 original source files. A mapped file or `implemented_unverified` status is not evidence of successful compilation or live behavior. The original source remains the reference; unsupported original capabilities remain unsupported.

## Acceptance rule

Keep `replacementReady: false` until every supported original behavior has an equivalent implementation, passing behavior tests, and required Windows/live-host checks. No use is made of the unused `ad-app`, `ad-sftp`, `ad-terminal` or `ad-credential` success-returning scaffolds.

## Important boundaries

- The production application and its saved settings/credentials are unchanged. The Rust app uses `%APPDATA%/AetherDesk-Rust` and separate Credential Manager targets; importing profiles does not import secrets.
- End remote session reports success only on acknowledgement. Detach preserves an attached desktop. Primary saved profiles have stable desktop IDs; duplicate recovery bookmarks are saved before launch and reopened through Saved desktop tabs.
- AI actions require action/message/chat approval. Grants are in memory and scoped to the conversation and workspace. Ordinary file tools are scoped; explicitly approved shell commands run with the account's broader permissions.
- Windows AI/tool processes are attached to a kill-on-close job before release. SSH commands use a gated process group and renewable lease; ten interpreted Linux fixtures passed in the cached AlmaLinux/Bash 4.4 environment, with compiler/live verification pending.
- Remote editors pin their authenticated session and host revision. Binary working copies open locally; upload-back is explicit. No automatic switch to a new host or local fallback occurs.
- Compiler tests are included in the build kit but were **not run**. Formatting, manifest metadata and offline recipe fixtures are separate checks and do not establish functional parity.
